\# LabVIEW 欧拉筛法（线性筛）实验项目



本项目基于 LabVIEW 2026Q1 社区版开发，实现了高效的欧拉筛法（Euler's Sieve）用于生成大规模质数，并针对 LabVIEW 的大数组内存管理进行了深度优化。



\## 📂 文件目录说明



| 文件名 | 类型 | 说明 |

| :--- | :--- | :--- |

| \*\*`prime1.vi`\*\* | 核心程序 | LabVIEW 虚拟仪器文件。包含算法主体，内部使用 \*\*原位元素结构（In Place Element Structure）\*\* 优化，消除了“写时复制”带来的性能退化。 |

| \*\*`front\_panel\_results.png`\*\* | 图片 | \*\*前面板截图\*\*。展示了程序的 UI 设计，包括数值输入控件（$N$）、开始按钮以及质数总数、运行耗时（秒）和质数列表的滚动显示结果。 |

| \*\*`back\_panel\_schematics.png`\*\* | 图片 | \*\*程序框图（后面板）截图\*\*。展示了优化后的数据流逻辑、双重循环结构以及原位操作的具体连线方式。 |

| \*\*`output.txt`\*\* | 文本数据 | \*\*质数数据输出文件\*\*。存储了程序运行后生成的质数列表，用于后续的正确性抽样验证（如 Python 脚本的全量检验）。 |

| \*\*`report.pdf`\*\* | 文档 | \*\*最终实验报告\*\*。由 `实验报告.tex` 编译生成的 PDF 文件，包含详细的实验环境、算法原理分析、性能优化前后的数据对比（$10$ 至 $10^8$ 规模）及内存瓶颈推论。 |

\## 💻 实验环境



\- \*\*开发工具\*\*：LabVIEW 2026Q1 社区版 (32-bit)

\- \*\*操作系统\*\*：Windows 11 家庭中文版 25H2

\- \*\*测试硬件\*\*：Lenovo XiaoXin Pro 14 IMH9 (Intel Core Ultra 5 125H @ 1.20GHz)



\## 🚀 核心优化摘要



在处理 $N \\ge 10^7$ 的大数据量时，传统的 `Replace Array Subset` 会触发写时复制，导致时间复杂度退化为 $O(N^2)$ 并导致程序卡死。

本项目通过在 `prime1.vi` 中引入 \*\*原位元素结构\*\*，直接在原数组内存地址上进行布尔标记修改，成功将时间复杂度维持在理论的 \*\*$O(N)$ 线性级别\*\*，使 $10^8$ 规模的计算耗时缩短至 \*\*2.55 秒\*\*。
