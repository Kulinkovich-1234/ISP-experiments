# Lab 6：DIY 光度滴定系统 — 从 3D 打印到自来水硬度

---

## 引言：当滴定不再靠肉眼

EDTA 络合滴定测水硬度是一个经典的分析化学实验。终点时铬黑 T 指示剂将从酒红变蓝。然而靠肉眼判断颜色变化，分辨率有限，而且人眼会疲劳。

实验目标很明确：**用光电传感器替代人眼，用注射泵替代手工滴定，用 Python 把整个流程串起来。**

原计划使用 NI LabView 完成全链路控制和数据记录，但是 NI LabView 是一个臃肿的、图形化界面的软件，可扩展性和灵活度不高，并且对 AI 的支持不够。因此转向万能的 **Python**。

这不是一套现成的设备。它由三个部分拼装而成：
1. **注射泵** — 串口控制，负责恒速推进 EDTA 溶液
2. **自制光度检测器** — LED 发光 + 光电二极管接收 + 跨阻放大器
3. **NI DAQ** — 采集光电压信号，同步控制注射泵时序

以及一个不起眼但关键的机械部件——**3D 打印的比色皿支架**。

---

## Part 1：比色皿支架 — 实验从建模开始

在搭建光路之前，需要先解决一个机械问题：怎样让 LED、比色皿、光电二极管的光轴对齐且环境光隔离？

答案是自己设计一个 3D 打印支架。

### 支架设计 (CadQuery)

用 Python 的 CadQuery 库参数化建模：

- 底板开四个安装通孔，适配光学面包板的孔距
- 中央凸起一个方形环，恰好卡入标准比色皿
- 两侧开槽，用于插入 PCB 板（LED 和光电二极管焊在 PCB 两端，插入后光路自动对准）
- Z 方向贯穿切槽，为电路板元件让出空间

这里有一个设计哲学：**让机械结构自动保证光路对准**。只要 PCB 插进槽里，LED 和光电二极管就天然地在比色皿两侧共轴——不需要手动调节。

### 方形盖

为了进一步减少环境光干扰，还设计了一个带中心通孔的盖子。中心孔是让滴定针头插入的。

### STL → 3D 打印

用切片软件（3MF 文件）导出到 3D 打印机。

## Part 2：硬件系统 — 三个模块的集成

### 注射泵与串口协议

这是一台通过串口（9600 baud）控制的步进电机注射泵。1 mL 注射器，内径 4.73 mm。

控制指令很有意思——全部是 `q` + 数字 + `h` + 参数 + `d` 的格式：

| 指令 | 含义 |
|------|------|
| `q1h05d` | 设置速度整数位 = 5 (mm/s) |
| `q2h00d` | 设置速度小数位 = 00 |
| `q6h2d` | 自动前进 |
| `q6h3d` | 自动后退 |
| `f1d` | 硬件回报：动作完成 |

> **⚠️ 一个昂贵的教训：** 厂商手册把 `q6h4d` 标注为"手动前进"，按理理解应该是"以设定的速度手动控制"。实际上它的意思是：以**最大速度**快进。这个误解导致两次推杆撞底，报废了两支注射器。而所谓的“自动前进”的意思才是按照指定速度和时间运动。后来全部改用 `q6h2d`（自动前进），并监听 `f1d` 信号做硬件同步。

### 光电检测器

在手工焊接电路板，强烈建议先去 B 站查看有关锡焊的教程掌握技巧。技巧会带来极大的效率和质量提升。跨阻放大器（TIA）把光电二极管的微弱光电流转换成电压。反馈电容用来抑制高频噪声，但也引入了一个 RC 低通滤波——这个电容，会成为后面数据处理的关键角色。

### DAQ 的角色

- **AI：** 以一定采样率采样光电检测器的输出电压

## Part 3：滴定控制 — 时序是核心

### 实验流程

```
① 人工准备：注入 MgSO₄/水样 + 缓冲液 + 指示剂 + 预加 EDTA
② 注射泵后退：吸取 ~700 µL EDTA 溶液
③ 注射泵恒速前进：推进 EDTA，同时 DAQ 以 100 Hz 记录光电压
④ 注射完成 → 保存 CSV → 绘制原始曲线
```

### 时序同步

滴定中最微妙的问题是时序同步。注射泵用 `f1d` 信号回报硬件动作完成，但在运行期间需要 DAQ 持续采样——两个设备之间没有硬件触发线。解决办法：

- 注射泵启动前进前，记录一个 `time.perf_counter()` 时间戳
- 用 `时间 × 速度` 推算理论推进体积
- 同时轮询串口的 `f1d` 信号（硬件完成时中断）

这意味着"体积轴"是由时间推导的，不是由编码器测量的——这是不确定度的一个来源。

## Part 4：信号处理 — 从噪声到终点

### 问题：高噪声 + 宽突跃

原始光电压信号有两个问题：

1. **高频 EMI (~0.1 V p-p)**：来自电源和磁力搅拌器。增大反馈电容可以降噪，但会进一步展宽滴定突跃，因此需要选定合适的电阻和电容。我的实验中由于电容过大导致**滴定突跃被展宽**。
2. **滴定突跃被展宽**：跨阻放大器的反馈电容构成了一个 RC 低通滤波器。指示剂变色理论上是一个阶跃，但经过 RC 滤波后变成了指数爬升。

### 滤波

策略是在硬件上设置较快的采样率（100 Hz）采集充足数据，然后离线做 SG 平滑（窗口 30，3 阶）。效果：RMS 噪声降低约一倍（原始 ~0.02-0.03 V，平滑后 ~0.009-0.014 V）。

### RC 阶跃响应模型

如果选用了过大的电容，会导致系统的响应迟滞。在滴定的时候，系统在突跃以后，输出电压才缓慢爬升到指定电压，使得电压数据显示的滴定突跃被严重展宽。展宽不是噪声——它是物理系统的特征。可以用模型来拟合：

$$V(\mu L) = V_1 + \Delta V \cdot \left[1 - e^{-(\mu L - \mu L_{\text{ep}})/\lambda}\right] \cdot u(\mu L - \mu L_{\text{ep}})$$

四个参数：
- $V_1$ — 基线电压（滴定前的光强）
- $\Delta V$ — 信号总变化（指示剂变色幅度）
- $\mu L_{\text{ep}}$ — 终点体积（我们要的答案）
- $\lambda$ — 展宽长度（RC 时间常数 × 注射速度）

用 Levenberg-Marquardt 在全曲线上做非线性最小二乘拟合。

这个模型的一个额外优势：**即使数据在突跃后没有完全建立平台就被中断，模型也能通过指数衰减的渐近行为外推终点。**

如果你的系统没有这样异常大的延时特性则不需要如此拟合。

## Part 5：结果 — 水有多硬？

### MgSO₄ 标定

两次校准滴定得到 MgSO₄ 浓度均值 ~0.01705 mol/L，相对偏差 2.3%。

未校准的实验（注射泵速度不同）结果显著偏离，说明注射泵的**速度校准**是定量分析的前提条件。

### 自来水硬度

一次完整实验 + 两次不完整实验。完整实验测得硬度约 430 mg/L（以 CaCO₃ 计）——按 WHO 标准属于**极硬水**。

两条不完整数据的终点分布在完整值两侧，离散度较大（±10%），符合预期——模型虽然能外推，但数据越少不确定度越大。尤其是 $\lambda$ 参数在数据不足时会触及预设上界，无法自由约束。

## 几点有意思的讨论

### 为什么 $\lambda$ 在不同实验中如此一致？

所有已校准实验的 $\lambda$ 在 96-110 µL 之间，对应 $\tau \approx$ 5.5-6.3 秒。这意味着展宽主要来自**检测电路的 RC 时间常数**，而非化学动力学因素。而且注射泵的恒速推进足够稳定，使 $\lambda$ 可以作为一个特征参数被稳定提取。

至于为什么理论和实际时间常数差别如此巨大，暂时没有明确的结论。

### 残差里有什么？

拟合残差在突跃附近有 ~0.02 V 的系统性偏离，不是白噪声。可能的解释：
- 指示剂变色本身有有限反应速率（终点附近平衡浓度低）
- 磁力搅拌器引起的对流造成指示剂浓度梯度逐渐扫过光路

但 R² 都在 0.97 以上，终点估计标准误通常 < ±1 µL。这个模型虽然不完美，但足够用了。

## 硬件教训清单

1. **盒子标签上的电阻阻值不可信。** 从标记"75 kΩ"的盒子里拿出的电阻实测 47 Ω。上板焊接后才检测出来，拆焊导致 PCB 焊盘氧化，被迫换点位。**所有元件上板前过万用表。**

2. **厂商说明书不一定说人话。** "手动前进"≠手动控制速度，它是以最快速度前进。花了两支注射器的学费才搞清楚。

3. **EMI 无处不在。** 磁力搅拌器会让 LED 按照同样的频率闪烁。软件滤波可以缓解但无法根除——未来方向是用 PCB 焊接一个抗干扰的电路，并做好电磁屏蔽。
